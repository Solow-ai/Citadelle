# Citadelle

Turn the open API of a business software into delegated agentic services, step by step, as tested in the field. One step, one result at a time.

🇫🇷 [Version française](#version-française)

## How it works

Each step is revealed only once it has been lived and tested at Solowai. This repository grows with the publications: it never shows the full method ahead.

Every step follows the same sections:

🎯 Objective · ✅ Prerequisites · 💡 Implications · 🛠️ Steps · ☑️ Checklist · ⚠️ Limits · 🧭 Experience · 🤖 Execution · ⏭️ Next

The steps already revealed are listed in [`index.md`](index.md). Each one exists in English (`EN/`) and French (`FR/`), under the same file name.
